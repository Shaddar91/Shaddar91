# Hi, I'm Shaddar91 👋

**I build autonomous, self-improving software systems — multi-agent task pipelines, Rust services, and the Terraform-defined cloud they run on.**

Most of my time goes into a self-hosted automation platform where voice and text turn into tasks that a fleet of AI agents plans, routes, and executes across my own infrastructure. I write Rust for the services that have to be fast and dependable, Python for the pipeline and data glue, and TypeScript/React on the front end. The whole stack is defined as code — GitHub repositories, AWS resources, and Kubernetes workloads are all provisioned with Terraform, so it rebuilds from scratch reproducibly. I'm especially drawn to systems that watch and correct themselves: knowledge graphs, retrieval-quality evaluation, and feedback loops that make the agents better over time. When I step away from the platform, I build small products end to end and self-host the tools I use every day.

### 🔭 What I'm building

- **[scriptsmith](https://github.com/Shaddar91/scriptsmith)** — Autonomous video-script production engine with per-channel guardrails and built-in quality assertion.
- **Seneschal** — A regulatory-intelligence platform, split across a [Rust/Axum API](https://github.com/Shaddar91/seneschal-api), a [React/TypeScript web app](https://github.com/Shaddar91/seneschal-web), and a [change-detection watcher service](https://github.com/Shaddar91/seneschal-watchers).
- **[the-cat-stable](https://github.com/Shaddar91/the-cat-stable)** — A small React + TypeScript gallery, built and shipped to AWS CloudFront.
